## 从哪张图开始看

可以先在两个版本中找到**自注意力热图**，看图回答同一个问题：当模型更新某个词的表示时，它从哪些词读取了更多信息？观察横纵轴是否标清了读取方和被读取方，颜色深浅的含义能否从图例读出，以及图中的例子能否解释正文里的那句话。

再看 **Transformer 架构图**。沿解码器中的交叉注意力追踪两路输入，看看能否分辨哪一路来自编码器、哪一路来自解码器。把同一概念的几张图并排看，更容易发现哪些标注帮助理解，哪些箭头容易引起误读。
